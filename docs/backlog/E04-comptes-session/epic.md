# E04 — Comptes, rôles & session

## Objectif

Permettre à chacun de s’identifier, créer un compte valide, et rester connecté confortablement sur mobile / tablette (dernier compte mémorisé).

## Périmètre

- **Inclus :** rôles SuperAdmin / Admin / Normal ; inscription simple (sans validation de compte au MVP) ; login / logout ; session persistante ; pseudo ; **invitation par e-mail** (lien PWA)
- **Exclus :** Play Store ; serveur SMTP auto-hébergé ; providers sociaux *(sauf demande)*

## Features

| Id | Feature | Statut |
|----|---------|--------|
| F01 | Rôles SuperAdmin / Admin / Normal | draft |
| F02 | Création de compte (sans validation MVP) | draft |
| F03 | Connexion, déconnexion, session persistante | draft |
| F04 | Pseudo public | draft |
| F05 | Inviter une personne (e-mail + lien) | draft |

## Notes

Public ado ⇒ comptes pour déposer une œuvre.  
Invitations = croissance du **cercle de confiance** via le **lien web**, sans store.
