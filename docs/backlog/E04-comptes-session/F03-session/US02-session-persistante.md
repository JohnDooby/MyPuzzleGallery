# US02 — Session persistante et dernier compte

**Feature :** F03  
**Statut :** done

## Récit

En tant qu’**utilisateur sur mobile ou tablette**,  
je veux **rester connecté et retrouver le dernier compte utilisé par défaut**,  
afin de **ne pas retaper mes identifiants à chaque visite**.

## Critères d’acceptation

- [ ] Après fermeture / réouverture de l’appli (PWA ou navigateur), la session est restaurée si l’utilisateur ne s’est pas déconnecté
- [ ] Sur le device, le **dernier compte** utilisé est proposé / reconnecté par défaut
- [ ] Comportement clair si plusieurs comptes ont été utilisés sur le même appareil *(à préciser : auto dernier seul, ou sélecteur)*

## Hors scope

- Synchronisation multi-appareils du « dernier compte » (sauf si session cloud le fait déjà)
