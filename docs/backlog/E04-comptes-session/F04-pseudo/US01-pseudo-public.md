# US01 — Définir et afficher un pseudo

**Feature :** F04  
**Statut :** done

## Récit

En tant qu’**utilisateur**,  
je veux **choisir un pseudo**,  
afin d’**apparaître publiquement sans exposer mon identité réelle**.

## Critères d’acceptation

- [ ] Le compte a un champ **Pseudo** obligatoire (ou fortement requis avant première publication)
- [ ] En public (accueil, explore, fiches), **seul le pseudo** est visible parmi les infos personnelles
- [ ] E-mail, nom civil, etc. ne sont **pas** affichés aux autres utilisateurs
- [ ] Le pseudo est utilisable comme filtre « auteur » dans l’explore

## Hors scope

- Changement de pseudo avec historique public *(règle anti-usurpation à trancher plus tard)*
