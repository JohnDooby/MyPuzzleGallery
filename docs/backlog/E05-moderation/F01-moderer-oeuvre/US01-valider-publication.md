# US01 — Valider ou refuser une demande publique

**Feature :** F01  
**Statut :** done

## Récit

En tant qu’**Admin**,  
je veux **valider ou refuser une image postée (demande publique)**,  
afin que **seul du contenu contrôlé soit visible de tous**.

## Critères d’acceptation

- [ ] File des œuvres en attente (demande « publique »)
- [ ] Pour chaque item : **aperçu image**, **titre**, **description**, **pseudo** auteur
- [ ] Actions **Valider** et **Refuser** clairement accessibles (tactile)
- [ ] Accessible **uniquement** aux rôles **Admin** et **SuperAdmin**
- [ ] **Valider** → visible publiquement (carousel, feed…)
- [ ] **Refuser** → reste non publique ; feedback auteur à définir
- [ ] Chaque décision est **audité** (E08)

## Hors scope

- Modération des commentaires (feature séparée, pas encore tranchée)
