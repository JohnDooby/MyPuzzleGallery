# US01 — Afficher un disclaimer

**Feature :** F02  
**Statut :** draft

## Récit

En tant qu’**utilisateur (ado / famille)**,  
je veux **être informé que l’activité est tracée**,  
afin de **savoir dans quel cadre je publie et j’interagis**.

## Critères d’acceptation

- [ ] Un **disclaimer** est visible (inscription et/ou première connexion et/ou page dédiée)
- [ ] Le texte mentionne au minimum : traçabilité des actions, **date**, **IP**, conservation de contenus liés aux actions
- [ ] Formulation adaptée familles / ado (clair, non juridique opaque — relecture humaine)
- [ ] Lien vers une page d’info plus complète si besoin

## Hors scope

- Conseil juridique professionnel (le PO fera valider le texte)
