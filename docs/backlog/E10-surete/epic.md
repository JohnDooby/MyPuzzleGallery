# E10 — Sûreté, signalements & protection des mineurs

## Objectif

Rendre la plateforme **ultra safe** pour un public ado / enfants : signalements, sanctions, garde-fous médias, transparence (disclaimer), cadre familial. Priorité absolue du produit (légal, RGPD, prévention contenus inappropriés / prédateurs).

## Périmètre

- **Inclus :** signaler une œuvre ; traiter les signalements (Admin+) ; retrait **rapide** du public ; ban / désactivation de compte + retrait public des œuvres (en conservant le flag « était publique ») ; règles privé vs public ; limites fichiers images ; disclaimer type cookies ; cadre âge / famille
- **Exclus :** likes anonymes ; commentaires (E09) ; validation de compte (reportée)
