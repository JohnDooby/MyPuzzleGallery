# F03 — Ban / désactivation de compte

**Épique parente :** E10

## Résumé

Admin / SuperAdmin peuvent désactiver (bannir) un compte. Toutes les publications qui étaient visibles publiquement sont **retirées du public**, tout en **conservant** l’information qu’elles étaient en mode public (trace).
