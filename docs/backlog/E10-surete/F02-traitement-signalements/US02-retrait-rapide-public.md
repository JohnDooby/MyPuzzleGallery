# US02 — Retrait rapide du public

**Feature :** F02  
**Statut :** draft

## Récit

En tant qu’**Admin**,  
je veux **retirer immédiatement une image du mode public**,  
afin de **couper la diffusion en cas de contenu à risque**.

## Critères d’acceptation

- [ ] Depuis le signalement (ou la fiche œuvre Admin), une action **Retirer du public** est possible en **peu de gestes** (priorité UX urgence)
- [ ] Dès validation de l’action, l’œuvre **disparaît** du carousel, du feed Explore et de toute vitrine publique
- [ ] L’œuvre peut rester visible **uniquement** pour l’auteur dans son espace privé *(à confirmer)*
- [ ] La décision est **auditée** (qui, quand, IP admin, œuvre)

## Hors scope

- Suppression définitive automatique (la suppression reste E03 ; ici = sortie du public)

## Notes

Distinct du refus de modération initiale (E05) : ici on agit **après** diffusion éventuelle.
