# US01 — Traiter un signalement

**Feature :** F02  
**Statut :** draft

## Récit

En tant qu’**Admin**,  
je veux **voir et traiter les signalements**,  
afin de **décider (retrait public, ban, classer sans suite)**.

## Critères d’acceptation

- [ ] File des signalements (œuvre, motifs, dates, nombre de signalements)
- [ ] Accès **Admin + SuperAdmin** uniquement
- [ ] Actions au minimum : **retirer du public** (US02), **classer sans suite**, **ouvrir le ban compte** (lien F03)
- [ ] Chaque traitement est **audité**
