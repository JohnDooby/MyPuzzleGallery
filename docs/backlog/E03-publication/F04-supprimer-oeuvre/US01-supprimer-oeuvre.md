# US01 — Supprimer une œuvre avec confirmation

**Feature :** F04  
**Statut :** done

## Récit

En tant qu’**auteur de l’œuvre**,  
je veux **supprimer mon dessin après confirmation**,  
afin d’**éviter une suppression accidentelle** (surtout au doigt sur mobile).

## Critères d’acceptation

- [ ] Action de suppression accessible depuis ma galerie / fiche œuvre
- [ ] Une **confirmation** explicite est exigée avant suppression définitive
- [ ] Après confirmation, l’œuvre n’apparaît plus (ni perso, ni public, ni explore, ni puzzle)
- [ ] Seul l’auteur (ou SuperAdmin selon règles) peut supprimer

## Hors scope

- Corbeille / restauration soft-delete *(sauf si on le décide plus tard)*
