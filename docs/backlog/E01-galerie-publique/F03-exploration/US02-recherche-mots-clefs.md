# US02 — Rechercher par auteur, galerie, dates

**Feature :** F03  
**Statut :** draft

## Récit

En tant que **visiteur / utilisateur**,  
je veux **filtrer l’exploration par mots-clés (auteur, galerie, dates)**,  
afin de **retrouver rapidement des publications**.

## Critères d’acceptation

- [ ] Je peux rechercher / filtrer par **auteur** (= **pseudo**)
- [ ] Je peux rechercher / filtrer par **nom de galerie**
- [ ] Je peux rechercher / filtrer par **dates** (période ou date de publication)
- [ ] Les résultats alimentent le même esprit de fil / liste scrollable
- [ ] Aucune donnée personnelle hors **pseudo** n’est exposée dans les résultats

## Hors scope

- Recherche plein texte OCR dans l’image
