# US02 — Enregistrer une réussite (difficulté)

**Feature :** F02  
**Statut :** draft

## Récit

En tant que **joueur**,  
quand **je termine un puzzle**,  
je veux que **ma réussite soit comptabilisée pour la difficulté choisie**,  
afin que **les stats restent justes**.

## Critères d’acceptation

- [ ] À la victoire, une réussite est enregistrée pour l’œuvre + la **difficulté** jouée
- [ ] L’action est **tracée** (audit E08) avec date (et métadonnées prévues)
- [ ] Règle anti-spam / multi-comptage *(une fois par user et difficulté ? — à trancher)*
